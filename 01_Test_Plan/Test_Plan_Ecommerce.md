# Test Plan – E-commerce Website

## Objective
Verify that the main user flows of an e-commerce website work correctly.

## Scope
Features to be tested:
- User registration
- Login
- Product search
- Add to cart
- Checkout process

## Testing Types
- Functional testing
- Usability testing
- Regression testing
- Exploratory testing

## Test Environment
Browser: Chrome
OS: Windows / Android

## Entry Criteria
Website available and stable.

## Exit Criteria
All critical bugs fixed and regression passed.
